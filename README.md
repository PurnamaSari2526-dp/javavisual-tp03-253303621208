Character Manager — TP3 (Java Visual SIH-6406)

Deskripsi

Character Manager merupakan proyek Java yang dibuat untuk menerapkan konsep dasar pemrograman berorientasi objek (OOP). Proyek ini mengelola data karakter menggunakan class, enum, constructor, getter dan setter, serta fitur level-up, mana, dan pemeriksaan status hidup karakter.

Fitur

- Menggunakan enum untuk menentukan tipe karakter.
- Memiliki dua constructor.
- Menggunakan encapsulation dengan atribut private.
- Memiliki getter dan setter.
- Menghitung ulang HP dan attack ketika level berubah.
- Memvalidasi mana agar tidak bernilai negatif.
- Memiliki method "isAlive()" untuk memeriksa status karakter.
- Menggunakan "toString()" untuk menampilkan data karakter.
