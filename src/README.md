# Character Manager — TP3 (Java Visual SIH-6406)

## Deskripsi Project

Character Manager merupakan program sederhana berbasis Java yang dibuat untuk memenuhi tugas TP3/AP3 Belajar Praktik mata kuliah Java Visual.

Program ini bertujuan untuk menerapkan konsep Object-Oriented Programming (OOP), seperti class, object, constructor, encapsulation, getter, setter, dan enum. Program juga dikembangkan dengan fitur tambahan berupa mana dan pengecekan kondisi hidup karakter menggunakan method isAlive().

## Fitur Program

1. Membuat objek karakter.
2. Menggunakan empat jenis karakter melalui enum.
3. Menggunakan dua constructor.
4. Mengimplementasikan getter dan setter.
5. Mengatur level karakter.
6. Menghitung HP dan attack berdasarkan level.
7. Menambahkan atribut mana.
8. Melakukan validasi mana agar tidak bernilai negatif.
9. Mengecek kondisi karakter menggunakan isAlive().
10. Menampilkan informasi karakter menggunakan toString().
